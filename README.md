# Micelio Digital

Grimorio interactivo de poesía electrónica, glitch y ritual sonoro.

## Descripción

*Micelio Digital* es una pieza de literatura electrónica y arte digital interactivo construida con HTML, CSS y JavaScript.

La obra explora la relación entre:
- cuerpo,
- tecnología,
- micelio,
- memoria,
- brujería,
- fuego,
- red,
- y transformación.

El proyecto está estructurado como un grimorio digital compuesto por distintas piezas visuales, poéticas y sonoras que reaccionan a la interacción de quien las recorre.

## Estructura

### Pieza I · Pupila Digital
Animación visual introductoria.

### Pieza II · Circuito Miceliar
Imagen ritual de red y expansión orgánica.

### Pieza III · Poemario Digital
Poemas interactivos con efectos glitch, animaciones y respuestas visuales al tacto/cursor.

### Pieza IV · Conjuro
Sistema sonoro generativo construido con Web Audio API.
Cada verso activa capas sonoras distintas que se acumulan para formar un paisaje ritual variable.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Web Audio API
